# Ручная проверка на устройствах

Статус: **не выполнена на физических iPhone / iPad**. Проверять production-сборку по HTTPS, сначала с интернетом, затем без него. Записать модель устройства, версию iOS / iPadOS, дату и результат.

## Основные сценарии

- [ ] iPhone: Safari, portrait и landscape. iPad: Safari, оба положения и Split View.
- [ ] В альбомном режиме телефона общая шапка скрыта; темы на главной листаются горизонтально. Последняя карточка «Мои пазлы» доступна свайпом и с клавиатуры, настройки и звук доступны в углу.
- [ ] В книжном режиме поле, лоток и стрелки целиком видны с открытой адресной строкой Safari. Проверить также после её скрытия.
- [ ] В книжном режиме телефона лоток показывает две крупные детали в один ряд. Стрелками доступны все детали на 3×3 / 4×4 / 5×5.
- [ ] В альбомном режиме видны шесть крупных деталей (3×2), стрелки находятся рядом с заголовком. Обе строки целиком помещаются по высоте, выступы соседних деталей не перекрываются.
- [ ] Последняя страница лотка сохраняет высоту панели, поле не прыгает при перелистывании и установке деталей. Поворот не сбрасывает собранное.
- [ ] В книжном режиме кнопки возврата, звука и подсказки доступны сверху; панель не перекрывает нижний индикатор iPhone.
- [ ] Запуск с главного экрана: иконка, название, standalone, safe areas.
- [ ] Нет горизонтальной прокрутки, все кнопки доступны при увеличении текста до 200%.
- [ ] Главная → категория → сложность → игра; повторное открытие прямого URL и refresh.
- [ ] Собрать 3×3, 4×4, 5×5. Все детали доступны через страницы лотка.
- [ ] Страница не двигается при drag. Кусочек не теряется при касании вторым пальцем.
- [ ] Близкое попадание принимается, неправильное мягко возвращается.
- [ ] Выступы деталей не обрезаются в лотке и при drag; удобно захватывать за центр и за выступ.
- [ ] На 3×3 / 4×4 / 5×5 соседние выступы и выемки совпадают, фотография непрерывна, наружный край прямой.
- [ ] Поле не показывает сетку и обводки установленных деталей. Нажатие на место по-прежнему работает, контур фокуса доступен с клавиатуры.
- [ ] Поворот устройства, уход из приложения и потеря захвата во время drag не оставляют зависшую деталь.
- [ ] Закреплённый кусочек не перемещается и не считается повторно.
- [ ] Нажатие на деталь, затем на ячейку работает без drag.
- [ ] Подсказку можно открыть и закрыть. После закрытия фокус возвращается к вызвавшей кнопке.
- [ ] Завершение показывает цельную картинку без сетки. «Ещё раз» сбрасывает игру, «Другой пазл» возвращает в категорию.
- [ ] Звук появляется после пользовательского жеста. Отключение работает и сохраняется после перезапуска.
- [ ] Фоновая мелодия плавно повторяется на границе 32 секунд, нет щелчков или наложения нескольких копий после быстрых нажатий.
- [ ] Музыка и звуки кусочков регулируются независимо, 0% выключает нужный канал; общий выключатель глушит оба. Настройки сохраняются после перезапуска.
- [ ] Кнопка с нотами открывает громкость прямо в игре на телефоне, закрытие окна сохраняет собранное.
- [ ] Сворачивание, блокировка экрана и переключение вкладки останавливают звук. Возвращение продолжает его либо ожидает следующего нажатия, если Safari требует жест.

## Личная библиотека

- [ ] Portrait, landscape, square: центрированный preview, без растяжения.
- [ ] Фото с EXIF-ориентациями, снимок с камеры, JPEG, PNG, HEIC из медиатеки.
- [ ] 12 / 48 Мп фото не приводит к закрытию страницы из-за памяти; при необходимости уменьшить допустимые лимиты.
- [ ] Отмена выбора файла и отмена preview ничего не сохраняют.
- [ ] Повторный выбор того же файла работает.
- [ ] Добавленная картинка доступна после перезапуска и без сети, на всех сложностях.
- [ ] Удаление требует подтверждения. Отмена сохраняет пазл, подтверждение удаляет только его.
- [ ] При отказе IndexedDB / заполнении хранилища показан понятный текст, повторная попытка возможна.

## PWA

- [ ] После первой полной установки service worker выключить сеть и перезапустить приложение.
- [ ] Проверить все встроенные картинки, включая ранее не открытые, и локальные шрифты.
- [ ] После установки кэша музыка запускается без сети; при ошибке загрузки музыки эффекты и игра остаются доступны.
- [ ] Обновить опубликованную сборку: начатый пазл не перезагружается сам.
- [ ] На экране категории доступны «Обновить» и «Позже», обновление загружает новую версию.
- [ ] Проверить project path GitHub Pages, например `/KidsPuzzles/`, и прямой hash-маршрут.

## Доступность

- [ ] VoiceOver произносит названия кнопок, ячеек, выбранных и установленных кусочков.
- [ ] Modal удерживает фокус, Escape закрывает окно на клавиатуре.
- [ ] Reduce Motion убирает выраженные анимации.
- [ ] Масштабирование страницы доступно вне деталей, нет глобального `user-scalable=no`.

## Результаты

Автоматически проверены смена размера лотка без потери прогресса, доступность всех деталей на трёх сложностях, переход с опустевшей последней страницы, завершение / повтор и звук в игровой панели. Эти тесты выполняются в jsdom и не заменяют проверку размеров и жестов в Safari.
